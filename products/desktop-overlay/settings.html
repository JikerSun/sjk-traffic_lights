Uninstall AI Traffic Lights

Follow these steps in order for a clean removal (app + global hooks + bridge data).

  1. Quit this app. Use menu bar AI Traffic Lights → Quit (or press ⌘Q). Do not run the commands below while the app is still running.
  2. Remove global hooks and bridge data. Open Terminal and run: Removes ~/.cursor/ai-traffic-lights/ and cleans entries in ~/.cursor/hooks.json (same as npm run uninstall:global-hooks).
  3. Remove the application.
  4. Finish up (recommended). Empty Trash if you deleted the app that way, then restart Cursor.
