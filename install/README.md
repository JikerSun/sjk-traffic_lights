# 安装包目录（不想看源码时从这里开始）

本目录按 **工具 / 交付方式** 分类，可直接下载子文件夹使用（GitHub 上可对子路径下载或整仓克隆后只进对应目录）。

| 路径 | 用途 | 状态 |
|------|------|------|
| [cursor/extension/](cursor/extension/) | Cursor 侧边栏扩展 `.vsix` | 需构建或从 Release 下载 |
| [cursor/workspace-hooks/](cursor/workspace-hooks/) | 任意项目的 Hooks + 桥接脚本 | 可直接 `bootstrap.sh` |
| [desktop/mac/](desktop/mac/) | macOS 桌面悬浮 App 安装包 | 预留 |
| [desktop/windows/](desktop/windows/) | Windows 桌面 App 安装包 | 预留 |
| [plugins/](plugins/) | 各 IDE / 编译器渠道插件 | 预留 |

详细说明见仓库根目录 [README.md](../README.md)。
