# Mac 安装包

## 下载（推荐）

从 GitHub Releases 下载 **`.dmg`**：

https://github.com/JikerSun/sjk-traffic_lights/releases

查找 **`desktop-v0.1.0`**（或最新 `desktop-v*`）中的：

- `AI Traffic Lights_0.1.0_aarch64.dmg` — Apple Silicon (M1/M2/M3…)

安装步骤见上级目录 [../README.md](../README.md) **§A**。

## 本地构建副本

若本目录存在 `*.dmg`，为开发者本地 `npm run build:desktop` 后的副本，**不一定与 GitHub Release 同步**。以 Releases 为准。
